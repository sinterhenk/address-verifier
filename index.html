1 API Keys

TomTom — 2,500 req/day free · no card Foursquare — 1,000 req/day free · no card OpenStreetMap — unlimited · no key needed
TomTom is used to geocode each address and search nearby POIs. Foursquare and OpenStreetMap are used as fallbacks when TomTom doesn't find a confident match. OSM is only queried when needed (to respect rate limits).

2 Business Name to Verify (optional)

If provided, each result is marked Match / Partial / Not found based on whether the name found contains the expected business name. All three sources are checked; the best match wins.

• Split columns: street, city, state, zip / postal_code
• Optional label: name, id, store_id
First row must be a header row. Comma or tab separated.
