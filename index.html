Address Verifier

Check what Google Maps says is actually located at your addresses

1 Google Maps API Key

Get a key at console.cloud.google.com → enable Maps JavaScript API & Places API. Your key stays in your browser and is never sent anywhere except Google.

2 Business Name to Verify (optional)

If provided, results will be marked Match / Partial / Not found based on whether the name found on Google Maps contains the expected name. Leave blank to simply see what's at each address.

3 Upload Addresses (CSV)

Click to browse or drag & drop a CSV file

Accepted columns (any order, case-insensitive):
• Single address column: address or full_address
• Split columns: street, city, state, zip / postal_code
• Optional label: name, id, store_id
First row must be a header row. Comma or tab separated.

4 Run Check

Google Places API: ~2 requests/address. Free tier: 5,000 req/month.
